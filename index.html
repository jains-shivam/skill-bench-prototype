What changed in V2 (and why)

Each row maps to one feedback point from the V1 walkthrough.

Feedback V1 today V2 proposal
Allow submit after prompt + golden solution Trainer has to also build environment, criteria, and pass Oracle before they can submit anything. Prompter wizard ends after Solution; submission unblocks the next role. A Tester takes it from there.
Full preview in draft and review mode Each step shows only its own form; reviewer sees a tabbed summary, no folder view. "Harbor preview" panel (folder tree + file viewer) on every submit step, in Task detail, and as the default reviewer tab.
Separate multi-step forms for Tester and Prompter One Trainer role with a single 7-step form covering everything. Two relay flows: Prompter (6 steps) and Tester (4 steps), each with its own dashboard / queue and stepper.
Allow Prompter to add skills No skill concept anywhere in the UI. New Skills wizard step with "From library" and "Author new" tabs. Skills compile into environment/skills/<id>/SKILL.md.
Evaluator: run with / without skills Evaluator picks agents, attempts, concurrency only. Required Skill mode radio: With / Without / Both (A/B). The cost estimate and feed reflect the choice; comparison shows a per-task skill lift.
Proper Harbor format preview Sections of the task are displayed in custom UI cards (no folder shape). Generated Harbor folder tree showing task.toml, instruction.md, environment/Dockerfile, environment/skills/, tests/rewardkit.yaml, solution/ - click any file to view.
File ownership during testing Single Trainer authors everything; no concept of who-owns-what during testing. Tester authors environment/Dockerfile, tests/test.sh, tests/rewardkit.yaml (visual builder / upload / raw editor). Prompter retains instruction.md, environment/skills/, solution/ and can revise them while testing is in progress (Revise my parts CTA). Everything else is read-only preview for each role.
Suggested demo order
  1. Open V1 - briefly walk through the Trainer wizard (Template → Test).
  2. Note any pain points the team mentioned (e.g. Trainer doing everything; no Harbor view).
  3. Open V2 - run the relay: Prompter submits prompt + solution + skills.
  4. Switch to Tester, pick up the prompt, add env + criteria, run Oracle, submit.
  5. Switch to Reviewer - first tab is the Harbor folder preview.
  6. Switch to Evaluator - new job with Skill mode Both (A/B), then comparison + trial detail.
